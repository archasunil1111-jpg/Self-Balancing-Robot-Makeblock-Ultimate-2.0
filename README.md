# Self-Balancing Robot using Makeblock Ultimate 2.0

## Overview

A college group project involving the design, assembly, configuration, and testing of a two-wheeled self-balancing robot using the **Makeblock Ultimate 2.0** platform.

The robot uses a **MegaPi controller, encoder motors, gyroscope sensor, and ultrasonic sensor** to demonstrate sensor-based robotic control and self-balancing behavior.

## Hardware Components

* Makeblock Ultimate 2.0 Kit
* MegaPi Controller
* MegaPi RJ25 Shield
* MegaPi Encoder/DC Motor Drivers
* 25mm DC Motors with Encoders
* Gyroscope Module
* Ultrasonic Module
* 90T Wheels
* 6AA Battery Holder
* Bluetooth Module
* RJ25 and Encoder Motor Cables

## Software & Technologies

* mBlock 5
* Block-based Programming
* Makeblock Ultimate 2.0 Platform
* MegaPi
* Gyroscope-based Tilt Detection
* Motor Control
* Sensor Integration

## Working Principle

The robot uses the gyroscope sensor to detect changes in its orientation.

The sensor provides angle information along different axes. The control program evaluates the detected tilt and responds by controlling the motors in the required direction.

This allows the two-wheeled robot to respond to changes in its orientation and maintain its intended movement and balance.

## Implementation

The project was implemented using the Makeblock Ultimate 2.0 platform and its associated mBlock programming environment.

The project involved:

* Assembling the mechanical structure of the robot
* Installing and configuring the MegaPi controller
* Connecting encoder motors and motor drivers
* Integrating the gyroscope sensor
* Integrating the ultrasonic sensor
* Configuring the robot using mBlock 5
* Testing sensor-based motor responses
* Calibrating and testing the assembled robot

The programming implementation was based on the programming resources provided for the Makeblock Ultimate 2.0 Self-Balancing Robot.
